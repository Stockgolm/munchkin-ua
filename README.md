Munchkin Digital — українська локалізація (мод)

Повний український переклад гри Munchkin Digital (Steam) з рідним шрифтом гри (і/ї/є/ґ).

Для гравців — встановлення (один раз)
1. Закрийте гру.
2. Розпакуйте `MunchkinUA-x.y.z.zip` у папку гри
   (Steam → Munchkin Digital → Керування → Переглянути локальні файли), щоб поруч із `Munchkin.exe`
   з'явилися `BepInEx`, `winhttp.dll`, `doorstop_config.ini`, `dotnet`.
3. Запустіть гру. Перший запуск довший (1–2 хв) — BepInEx готується. Далі — як зазвичай.

Більше нічого робити не треба:
- файли гри не змінюються — мод переживає оновлення гри й «перевірку цілісності» Steam;
- свіжий переклад підтягується автоматично при кожному запуску (з GitHub);
- якщо гра додала нові тексти, мод перекладе їх сам (Google Translate) — вони з'являться з наступного запуску.

Як це працює
- `plugin/` — BepInEx 6 (IL2CPP) плагін:
  - перехоплює `TextAsset.text` для `en_US`/`uk_UA` і підставляє переклад
    (шари: remote з GitHub > вбудований `uk_UA.txt` > машинний `uk_UA.auto.txt`);
  - у пам'яті повертає кирилицю у шрифти CaslonAntique / Quasimodo (`data/fonts` — офіційні кириличні
    версії шрифтів із гри 2024 року).
